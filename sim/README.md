# 📊 Simulation & Execution Scripts

This directory is dedicated to the scripts and configuration files needed to compile, simulate, and extract coverage reports for the IP using EDA tools.

1. **Compilation:** Compiling the RTL and Testbench files.
2. **Simulation:** Running the simulation to check functional correctness (generating `.vcd` or `.fsdb` for waveform viewing).
3. **Coverage:** Generating Code Coverage metrics (Statement, Branch, Toggle).
